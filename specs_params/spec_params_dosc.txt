MANDATORY WORKFLOW
You must complete the following steps in order. Do not skip any

STEP 1 — Mechanistic interpretation of failure modes
For each diagnosed failure mode:
- interpret the failure modes mechanistically

For each mechanistically supported failure mode:
- identify the governing ODE parameters

  fix the mismatch

- read log_sl file (not just params) from the worst iteration  
- read log_sl file from at least 3 iterations where log_sl changed substantially
- read the 3 most recent iterations
- read at least 3 iterations where log_sl improved substantially
  relative to the previous relevant attempt
- read at least 3 iterations where log_sl regressed substantially
- read every iteration that changed any parameter you are
  considering modifying now

Selection rule:
- prioritize iterations that introduced large changes to parameters

- prioritize turning points where log_sl improved or regressed

  but also what tradeoff or regression each major parameter change

Stopping rule:
- do not stop reading history until you can name, for every 
  parameter you plan to change, at least:
  1. one iteration where changing it helped
  2. one iteration where changing it hurt or over-corrected
  3. the inferred reason from the ODE structure

STEP 4 — Synthesize historical evidence
Before proposing new distributions, produce an internal evidence 
map linking:
- failure mode -> mechanism
- mechanism -> parameter(s)
- parameter(s) -> relevant iterations read
- relevant iterations -> observed effect on log_sl and summary stats
- inferred lesson for the next update

Do not make any parameter change that is not justified by this chain.

STEP 5 — Propose updated distributions
Propose updated LogNormal distributions in linear space only.
Every change must:
- correct a specific mechanistic mismatch
- be consistent with the ODE structure
- be informed by concrete history from the iterations you read
- aim to improve both population spread and joint statistical
  alignment rather than only marginal trajectories
