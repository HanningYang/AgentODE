DEFINITION: TIGHTLY INFORMATIVE
A prior is tightly informative if it:
- Concentrates probability mass sharply around the most likely
  parameter value given the ODE structure and observed trajectories
- Uses the SD only to express residual uncertainty in the point
  estimate itself, NOT to reflect population-level variability
  across trajectories
- Treats inter-trajectory variability as arising from initial
  conditions, NOT from parameter spread
- Rules out physically implausible values
