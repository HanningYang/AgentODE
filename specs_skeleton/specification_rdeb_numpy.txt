"""
Find the symbolic skeleton of an ODE system that represents
inflammatory biomarker dynamics in patients with Severe
Recessive Dystrophic Epidermolysis Bullosa (RDEB), a rare genetic
blistering skin disorder characterised by chronic wounds,

The system involves four coupled state variables measured
longitudinally over time in paediatric RDEB patients:

    - albumin   (g/dL):  Serum albumin, a marker of nutritional
                         status and chronic inflammation.
    - log_crp   (a.u.):  Log10-transformed C-reactive protein,

    - hemoglobin (g/dL): Haemoglobin, a marker of anaemia severity.
    - bmi_rel   (a.u.):  BMI relative to age- and sex-matched WHO
                         healthy reference. A value of 0 indicates
                         a healthy BMI; negative values indicate
                         underweight relative to peers.

The time unit is months since first hospital visit (follow-up
records). Observations span t in [0, 144.0] (up to 12 years
of follow-up).


HARD CONSTRAINT:
- The parameter array has at most MAX_NPARAMS = 12 slots.
- Do NOT skip indices.
- Use only as many parameters as necessary; avoid introducing
  redundant parameters.
- You must not use any params[k] with k >= MAX_NPARAMS.
- Do NOT hardcode or predefine numeric values for parameters.
  All numeric constants that govern the dynamics must be
  represented as params[k] entries. The parameter values
  will be optimised against data — do not assume or fix them.
"""

    """Symbolic skeleton for a 4-variable ODE system.

    Args:
        biomarkers: A numpy array containing
                    [albumin, log_crp, hemoglobin, bmi_rel].
        params: Array of numeric constants or parameters to be optimized.
                You must not use any params[k] with k >= MAX_NPARAMS.
    Returns:
        A numpy array representing the temporal derivatives (d/dt)

    log_crp    = biomarkers[1]
    hemoglobin = biomarkers[2]
    bmi_rel    = biomarkers[3]

    d_hemoglobin = params[2] * hemoglobin
