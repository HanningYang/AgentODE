Find the symbolic skeleton of an ODE system representing
a three-variable biofilm metabolic oscillation model.

The system involves three coupled state variables:

    - Gp (concentration, mmol/L): Peripheral glutamate
    - A  (concentration, mmol/L): Ammonia
    - Gi (concentration, mmol/L): Internal glutamate

The time unit is hours. Observations span t in [0, 25.0]

HARD CONSTRAINT:
- The parameter array has at most MAX_NPARAMS = 8 slots.
- Do NOT skip indices.
- Use only as many parameters as necessary; avoid introducing
  redundant parameters.
- You must not use any params[k] with k >= MAX_NPARAMS.
"""

import numpy as np

MAX_NPARAMS = 8
params = [1.0] * MAX_NPARAMS


@system.evolve
def system(biomarkers: np.ndarray, params: np.ndarray) -> np.ndarray:
    """Symbolic skeleton for a 3-variable ODE system.

    Args:
        biomarkers: A numpy array containing [Gp, A, Gi].
        params: Array of numeric constants or parameters to be optimized.
                You must not use any params[k] with k >= MAX_NPARAMS.
    Returns:
        A numpy array representing the temporal derivatives (d/dt)
        of the state variables [dGp/dt, dA/dt, dGi/dt].
    """
    Gp, A, Gi = biomarkers

    # ---- Gp dynamics ----
    dGp = params[0] * params[1] * Gp - params[2] * A * Gp - params[3] * Gp

    # ---- A dynamics ----
    dA = - params[4] * A + params[5] * Gi

    # ---- Gi dynamics ----
    dGi = params[3] * Gp - params[5] * Gi

    d_biomarkers = np.array([dGp, dA, dGi], dtype=float)
    return d_biomarkers
