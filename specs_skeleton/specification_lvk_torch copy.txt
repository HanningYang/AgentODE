"""
Find the symbolic skeleton of an ODE system describing the coupled
dynamics of two interacting species observed over time.

The system involves two state variables:

    - x: Population of species A
    - y: Population of species B

Observations span t in [0, 50] with 51 timepoints (dt = 1.0).

HARD CONSTRAINT:
- The parameter array has at most MAX_NPARAMS = 8 slots.
- Do NOT skip indices.
- Use only as many parameters as necessary; avoid introducing
  redundant parameters.
- Always index parameters and biomarkers with ellipsis notation
  params[..., k] and biomarkers[..., k] — never use params[k]
  or biomarkers[k] directly.
"""

MAX_NPARAMS = 8

    """Symbolic skeleton for a 2-variable ODE system.

    Args:
        biomarkers: A torch tensor containing [x, y].
        params: Tensor of numeric constants or parameters to be optimized,
                shape (batch, n_params). Access parameter k for all samples
                via params[..., k]. You must not use any params[..., k] with
                k >= MAX_NPARAMS; using more than 8 parameters is invalid.
    Returns:
        A torch tensor representing the temporal derivatives (d/dt)
        of the state variables [dx/dt, dy/dt].

    x = biomarkers[..., 0]
    y = biomarkers[..., 1]

    # ---- x dynamics ----
    dx = params[..., 0] * x

    # ---- y dynamics ----
    dy = params[..., 1] * y
